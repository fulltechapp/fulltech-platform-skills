# bip-fim-de-tarefa

Mod do Claude Code (hooks module). Quando um turno do Claude ou de um subagente termina, toca um bip (sons sintetizados, sem direitos de terceiros) e mostra um toast com a tarefa, a duração e os tokens. Enquanto trabalha, a linha de status mostra a ferramenta em uso por cada agente. Erro/recusa toca um som grave; interrupção não toca.

Instalação: `/plugin marketplace add <caminho ou repo fulltech-platform-skills>` e `/plugin install bip-fim-de-tarefa@fulltech-platform-skills`.
